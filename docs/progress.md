按 `plan.md` 逐步实施。以下为代码实际状态，不替代真实外部环境的验收。

## 自动更新与命令行

应用更新增加单次发起的自动流程：服务端检查、下载校验、暂停新任务、等待现有任务和投递结束，再自动停机备份、切换及重启；流程不依赖页面轮询。准备状态保存自动更新意图，等待期间可取消并恢复接收，过期准备包不会触发降级。页面显示简洁阶段和不定进度条，启动失败继续恢复旧程序及完整备份。

程序支持 `serve`、`help`、`version`、`update` 命令，兼容 `-h` / `--help` / `-help`、原有启动选项及安装器前置参数。本机运行实例通过私有 Unix socket 接收 `update` 命令；未运行的安装器部署可下载校验后由后台更新进程自动启动。Linux/macOS/Windows WSL 沿用安装器布局；Docker、源码和外部服务管理器部署提供手动指引。已通过全量 Go 竞态、go vet、前端构建、Chromium 桌面/320px/390px 回归和 macOS arm64 交叉编译；真实安装包的网页自动更新、命令行更新运行中实例、未运行实例更新后启动三条本地 HTTPS Release 链路均通过，验证登录、模型密钥、会话、数据与完整备份保留。真实 Windows WSL 更新仍需对应环境验收。说明见 [application-updates.md](application-updates.md)。

## 模型列表、知识库调优与 Markdown 正文

模型配置增加按当前未保存值获取列表：Go 调用标准 models 接口，支持已保存密钥复用及当前密钥覆盖，结果只在页面内存供下拉/手填，不保存列表、不改变连接版本。带认证/CSRF、20 秒期限、2 MiB 上限、无重定向及安全错误。服务地址、协议、密钥或连接变更时清空列表并忽略旧响应。

知识库分片由 1000/150 调整为最多 600 字符、重叠 80 字符，优先句末、换行和空白边界；管理检索摘要由 600 缩短为 140/220 字符，优先覆盖更多查询词。Agent 保留原摘要预算与完整来源读取。已有文档通过重新索引应用新规则，旧版本不改写。事务内复用插入语句，段落正则复用；本地 44,800 字符重复语料小样的检索内存分配约降低 52%，详细数据及局限见 [knowledge-tuning.md](knowledge-tuning.md)。知识库管理/新建按钮合并成同高操作组，桌面与移动端保持相邻。

对话正文使用 react-markdown 10.1.0 + remark-gfm 4.0.1，支持标题、列表、表格、引用、代码块、任务列表和删除线；历史及流式内容均可渲染。原始 HTML 保持文本、危险 URL 使用解析器安全过滤，图片只显示显式链接。代码和表格单独横向滚动，memo 避免流式更新时反复解析全部历史消息。

验证包括完整构建、25 项 Runtime 测试、Go 全量竞态测试、go vet、完整进程 E2E 与 Chromium 全流程。新增覆盖列表取当前值/密钥/无保存、句子边界/坐标/无丢字、紧凑摘要/完整来源、Markdown 结构与 XSS/危险链接/远程图片处理，以及 320px/390px 布局和知识库操作组对齐。

## 模型配置与紧凑交互

模型栏目采用紧凑连接列表和分组表单，支持连接名称、三种 API 协议、上下文窗口、最大输出、推理能力/强度、Temperature、Top P 及 Chat Completions 输出长度字段覆盖。配置贯通 Go 保存/校验/迁移、排队快照、私有协议和 Pi AI 真实请求；使用已锁定 1.3.0 SDK 的原生适配器。旧客户端省略 options 时保留参数，旧数据迁移为此前实际使用的 32768/4096 默认值，密钥留空规则保持。

当前 schema 10，从版本 1–9 自动迁移。旧的 24000 字节配置已停用并移除普通配置入口。Runtime 按模型窗口、最大输出预留和 SDK Token 估算检查；Go 不再混用 Token 与字节，另保留内部 8 MiB 资源保护。估算不等于供应商精确分词。现已支持 Agent 级最近轮数、时间窗口、自动摘要与完整历史策略；摘要触发、失败和重启已通过本地测试，详见 [agent-policy.md](agent-policy.md)。删除对话移到标题栏确认弹窗，支持取消、Esc 和默认聚焦取消；输入区不再展示固定删除区域。站点增加同品牌 SVG favicon。

本地验证包括协议专属探针、三种 SDK 实际 HTTP/SSE 请求、参数快照与迁移、模型 Token 预算、旧字节配置兼容、长输入及独立资源保护、浏览器完整流程与 320px/390px 布局、参数进入实际模型请求、弹窗与图标；外部供应商兼容性仍需真实环境验收。参数和限制见 [models.md](models.md)。

## 知识库工作台重构

知识库采用顶部选择器与“文档管理 / 检索测试”双页签，移除常驻的新建、上传和检索表单。文档列表仅展示名称、状态、已发布版本及更多操作；支持名称搜索、状态筛选、详情、替换、重试与重新索引。创建/编辑、上传/替换和删除使用弹窗，删除默认聚焦取消；pending 禁止重复提交与关闭。上传限制及 PDF 能力提示在上传弹窗按需展示。

每个知识库独立维护文档与检索状态，迟到的旧请求不能覆盖当前库，上传后旧列表回包也不会丢弃新文档；轮询串行执行，索引发布或删除后清空过期检索结果。桌面与 320px/390px 的列表、弹窗、菜单及来源链接通过真实 Go/Node Chromium 流程验证，包含筛选、延迟响应跨库切换、取消/Esc/遮罩、失败替换保留旧版本、成功替换与历史/删除引用。
