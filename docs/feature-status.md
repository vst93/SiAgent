## 本轮补齐的维护漏项

此前进度说明遗漏了计划中的“管理员清理会话、后台磁盘提示、默认日志轮转”，不能将此前的“本地可实现工作已完成”理解为已逐条满足全部维护要求。本轮已补实现和验证，并将生产验收继续单列。

- 管理员点击会话标题栏的删除图标，在弹窗内核对、勾选确认并提交。已有任务未释放或有待发送回复时拒绝清理；不会自动取消任务或撤销外部操作。
- 删除请求先落库并隐藏旧会话，阻止新消息进入。后台请求 Runtime 删除会话 SQLite/WAL/SHM 和执行记录，收到确认后才删除 Go 的消息、运行、工具和来源关联。
- 超时、确认丢失、服务重启会保留清理请求，按同一幂等流程重试。单个请求失败不会阻塞其他清理请求。
- 企微清理后解除当前会话映射，下一条新消息创建新会话。保留应用/MsgId/指纹等去重标识，清除对应入站正文、成员和出站正文，重复回调不会重新创建任务。
- 模型、助手、知识文件、其他会话不受此清理影响。删除不是安全擦除；SQLite 可能保留空闲页，历史备份也可能保留已删除内容。
- “配置 → 运行与维护”显示数据总量、文件数、所在磁盘容量/可用量、清理请求数量。统计不跟随目录内符号链接，最多扫描 2 秒/20 万条目；未完整统计明确标为部分结果。可用空间不足 1 GiB 或低于 10% 显示提示，不自动删业务数据。

## 计划允许的替代方案与扩展

- **Agent 策略**：会话类型、群共享范围、空闲重置、最近轮数/时间窗口/自动摘要/完整历史，以及思考摘要、工具详情、来源与提示均可配置；原生 compaction 的成功、失败及重启已通过本地验证，真实模型摘要质量仍待验收。见 [agent-policy.md](agent-policy.md)。
- **知识库 MCP 双向适配**：已预留 Provider/适配边界，尚未实现专用 MCP 接入或暴露；`knowledge.md` 的第一版优先范围允许预留扩展位置，通用 MCP 已实现。
- 多租户、向量检索、OCR/Office、通用不可信代码沙箱、工作流及微信客服等额外渠道不在首版范围；企微智能机器人群聊已支持，仍需真实企业验收。

操作与验证记录见 [部署维护](deployment.md)、[发布检查](release-checklist.md)、[企业微信验收](wecom-validation.md)。当前应按“本地功能候选版本”使用，不按正式生产兼容版本对外宣称。
