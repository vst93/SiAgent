# SiAgent 界面与交互打磨计划

> 状态：方向已确认（Calm Precision = B + A），第一轮实现已完成。
> 范围：现有 React + CSS 工作区的视觉、排版、布局、交互细节与响应式打磨。
> 不包含：新增业务功能、重写前端框架、引入外部字体 CDN。暗色模式已作为一等模式实现。

## 0. 设计判断

**Design Read：** 这是一个面向技术管理员的自托管企业 AI 工作台，视觉语言应当是冷静、精确、有秩序感，而不是通用 AI 仪表盘。

- **Redesign 模式：** Redesign - Preserve。保留主要文案、路由、表单字段和业务流程；调整桌面导航结构、视觉系统、排版、布局节奏和交互细节。
- **三个拨盘（产品 UI 语境）：**
  - `DESIGN_VARIANCE: 4`：克制，不做实验性布局；
  - `MOTION_INTENSITY: 2`：只保留状态反馈和轻微过渡；
  - `VISUAL_DENSITY: 6`：信息密度偏高，但保留呼吸感。
- **设计系统：** 现有 React + 手写 CSS，不引入 Tailwind、组件库或设计系统包。继续使用 Phosphor Icons。
- **品牌保留：** 青绿色品牌、`S·` 标记、现有 Logo 结构。可以微调比例和质感，但不换品牌。

## 1. 现状审计

### 1.1 已有优点

- 信息架构清楚：Agent 对话 / 配置双工作区，配置侧栏分组合理；
- 关键流程完整：模型、Agent、知识库、Skills/MCP、渠道、维护；
- 已有键盘焦点、`aria-*`、减少动态效果、移动端适配；
- 图标统一使用 Phosphor；
- 浏览器测试覆盖主要流程和 320px/390px 布局。

### 1.2 主要问题

**整体气质**

- 青绿 + 白卡片 + 浅灰背景的组合比较像通用 AI SaaS，缺少“自己的产品气质”；
- 卡片、边框、浅色底、圆角大量重复，层级靠容器堆叠，而不是靠排版和留白；
- 标题字号偏大且重复：`h1`/`h2` 都是 27px，页面标题和区块标题层级不清；
- Avenir Next 只在 macOS 可靠，Linux/Windows 回退后观感不一致；
- 数字、时间、元数据没有使用等宽数字，表格和状态不够“工程感”。

**顶栏与导航**

- 顶栏同时有：品牌、模块切换、两个星标、默认页文字、退出登录，信息密度过高；
- “默认：Agent 对话”是技术实现细节，不应该常驻顶栏；
- 两个模块各自带星标，交互重复且不易理解；
- 配置侧栏有“工作区配置”标题、说明、分组标签、底部提示，重复信息多；
- 配置页标题与内容区标题有时重复，形成两层“标题墙”。

**对话工作区**

- 对话记录是覆盖式面板，桌面端没有稳定的历史栏，切换会话不够直接；
- 头部操作（Agent 选择、新对话、删除、对话记录）挤在一行，优先级不清；
- 消息区最大宽度、行高、段落间距没有统一节奏；
- 空状态使用 `S·` 大符号 + eyebrow + 标题 + 两行说明，偏“AI 模板感”；
- 用户消息和助手消息的视觉区分不够成熟，头像方块偏重；
- 运行状态、工具调用、来源、诊断信息层级多，容易变成“信息堆”。

**配置工作区**

- 模型、Agent、知识库、Skills/MCP 各自有一套列表/编辑器样式，细节不一致；
- 资源列表用卡片堆叠，选中态和悬停态不够清晰；
- 表单字段间距、标签、帮助文字、错误提示没有统一规范；
- 弹窗、菜单、复选框、单选框、开关的视觉语言不统一；
- 知识库工作台 tabs、筛选、列表、详情、检索测试之间的层级偏复杂。

**细节**

- 圆角 6/10/12 混用，缺少明确规则；
- 阴影少但存在，颜色和背景不匹配；
- 状态点、标签、eyebrow 使用偏多，容易显得装饰化；
- 部分文案过于解释性，像文档而不是产品界面；
- 移动端顶栏和配置导航仍偏拥挤。

## 2. 设计方向：Workbench

关键词：**纸感、墨色、细线、单一强调色、等宽元数据、克制的动效。**

### 2.1 视觉语言

- **背景：** 冷调纸白，不使用纯白大面积铺底；主内容区可用纯白，但用细线和留白分层。
- **文字：** 墨色，不使用纯黑；主文字、次级文字、弱文字三级。
- **强调色：** 保留青绿，但降低饱和度，作为唯一强调色；成功/在线使用同一色系，危险使用低饱和红。
- **边框：** 1px 细线为主；阴影只用于浮层和弹窗，且带背景色调。
- **圆角规则：**
  - 交互控件：6px；
  - 面板/卡片：10px；
  - 弹窗/浮层：12px；
  - 不使用全圆角胶囊，除非是状态标签。
- **图标：** 继续 Phosphor，统一 16/18px，`strokeWidth` 保持一致。
- **禁止：** 渐变文字、外发光、彩色状态点装饰、厚重投影、过多胶囊标签、AI 紫。

### 2.2 字体与排版

字体栈：

```css
--font-sans:
  ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
--font-mono:
  ui-monospace, "SFMono-Regular", "Cascadia Code", "JetBrains Mono",
  Menlo, Consolas, monospace;
```

规则：

- 正文 13–14px，行高 1.65；
- 页面标题 22–24px，字重 650，字距 -0.4px；
- 区块标题 17–18px，字重 650；
- 元数据 11–12px，使用 mono，颜色弱化；
- 数字、时间、ID、计数使用 `font-variant-numeric: tabular-nums`；
- 不再让 `h1`/`h2` 都使用 27px；
- 减少 eyebrow 和全大写小标签，只在真正需要分组时使用。

### 2.3 间距与布局

- 4px 基础网格：4 / 8 / 12 / 16 / 24 / 32 / 48；
- 页面内边距：桌面 24–32px，移动 16px；
- 表单字段间距 16–20px；
- 列表行高 40–48px；
- 配置内容最大宽度 1080–1120px；
- 对话正文最大宽度 760–820px；
- 所有滚动容器使用 `scrollbar-gutter: stable`。

### 2.4 顶栏

目标：一屏只保留必要信息。

- 高度 56px，单行；
- 左侧品牌；
- 中间模块切换，做成更克制的 segmented control；
- 右侧只保留一个“固定默认页”入口和退出；
- 移除常驻的“默认：xxx”文字；
- 星标不再放在每个模块按钮里，改为一个统一的“固定当前页”操作，或收进账户菜单；
- 移动端保留品牌标记、模块切换、退出，隐藏次要文字。

### 2.5 配置工作区

- 侧栏宽度 220px；
- 移除“工作区配置”大标题和重复说明；
- 分组标签更小、更弱；
- 选中项使用左侧 2px 强调线和浅底色，而不是整块深色；
- 底部提示收进帮助入口或页面底部，不常驻；
- 内容区只保留一层页面标题；
- 列表/编辑器使用统一的资源面板结构；
- 表单统一 label 在上、helper 在下、error 在字段下方；
- 减少嵌套卡片，改用分隔线、留白和分组标题。

### 2.6 对话工作区

- 桌面端使用固定历史栏（约 240px），不再默认覆盖；
- 头部只保留：会话标题、Agent 选择、新对话、更多操作；
- 删除、对话记录等低频操作收进更多菜单；
- 消息正文最大宽度 760–820px；
- 用户消息使用浅色块或右对齐，助手消息保持开放排版；
- 头像缩小，减少方块感；
- 空状态简化为：一句标题 + 一句说明 + 一个主操作，移除大号 `S·` 和 eyebrow；
- 运行状态、工具、来源、诊断按“摘要优先、详情展开”组织；
- 输入区固定底部，边框和焦点状态更清晰。

### 2.7 组件规范

- **按钮：** primary / secondary / ghost / danger 四种；高度 32/36px；active 位移 1px；禁用态降低对比但不消失。
- **输入：** 高度 36/40px；focus ring 2px 强调色；placeholder 只做示例，不做标签。
- **标签：** 状态标签使用小号、低饱和背景，不滥用。
- **列表：** 行分隔用底边线，不用每行卡片；hover 和 selected 明确。
- **弹窗：** 12px 圆角；遮罩加深；Esc 关闭；焦点回到触发点。
- **空/加载/错误：** 三种状态都有明确布局；加载使用骨架或一行状态，不用通用转圈。
- **动效：** 120–180ms ease-out；只用于 hover、展开、弹窗、状态变化；尊重 `prefers-reduced-motion`。

## 4. 验收标准

### 视觉

- 页面只有一个强调色，且全站一致；
- 圆角规则统一：控件 6px、面板 10px、弹窗 12px；
- 标题层级不超过三级，页面标题和区块标题不重复；
- 正文行宽不超过约 80 字符；
- 数字/时间/ID 使用等宽数字；
- 没有渐变文字、外发光、厚重投影、装饰性状态点；
- 卡片只在需要表达可选择/可分组时使用，不用卡片堆页面。

### 交互

- 顶栏在 1024px 以上单行，不换行；
- 配置侧栏在 1024px 以上固定，移动端可横向滚动或选择；
- 对话历史在桌面端可直接切换，移动端可打开/关闭；
- 所有按钮有 hover / active / focus / disabled；
- 所有表单有 label、helper、error；
- 所有弹窗支持 Esc、焦点管理、遮罩关闭；
- 所有异步区域有 loading / empty / error；
- 所有页面在 320px 下无横向溢出。

### 可访问性

- 文字对比度达到 WCAG AA；
- 焦点环清晰可见；
- 纯图标按钮有 `aria-label`；
- 键盘可完成主要流程；
- `prefers-reduced-motion` 生效。

### 工程

- `npm --prefix web run build` 通过；
- `npm --prefix web run test:browser` 通过；
- Go 嵌入资源构建通过；
- 不改变既有路由、表单字段、主要文案和业务测试选择器；
- CSS 继续集中管理，新增变量优先于新增魔法数字。

## 5. 不做
