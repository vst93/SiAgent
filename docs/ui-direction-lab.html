SiAgent / UI direction study / 2026

四个可以真正落地的界面方向

不是四套配色，而是四种结构、密度和排版逻辑。每个方向都基于同一组产品约束：长时间使用的桌面工作台、中文优先、技术管理员、对话 + 复杂配置并存。先选方向，再谈组件。

怎么选

先看缩小后的整体气质，再看字号和行高，最后看侧栏与输入区。不要先挑颜色。

推荐组合：B 的结构 + A 的克制。如果只想选一个，选 B。

Design read 自托管企业 AI 工作台，面向技术管理员；需要的是一种安静、精确、可长期使用的桌面工具感，而不是通用 AI SaaS 仪表盘。默认浅色，深色作为完整的一等模式。
DIRECTION A

Cupertino Calm

苹果式的安静与留白：半透明侧栏、统一工具栏、少边框、软层级。让产品像 macOS 自带应用，而不是网页。
