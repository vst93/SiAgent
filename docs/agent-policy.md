# Agent 会话、上下文与回复策略

在“配置 → Agent”选择助手，通过“会话限制”“上下文”“回复输出”页签设置策略，点击“保存助手”。这些页签与基本信息使用同一份 Agent 配置；切换页签保留未保存的修改。知识库和工具授权仍分别保存。

默认时区为北京时间 `Asia/Shanghai`，允许私聊和群聊，群内按成员隔离；不因空闲自动重置，允许 `/new`；上下文保留最近 20 轮；隐藏思考摘要、展示简要工具状态、检索来源及渠道处理中提示。升级后的既有助手采用这些默认值，完整历史不删除。

策略在任务提交时与模型、角色、工具和知识库授权一起冻结。修改配置只影响新接收的任务，排队任务继续使用原策略。旧格式运行快照仍可读取，并按原完整历史与输出语义解释。

## 时区与每轮时间

在“基本信息”设置 IANA 时区，如 `Asia/Shanghai`、`America/New_York` 或 `UTC`；服务端校验时区，不接受随主机变化的 `Local`。既有 Agent 未配置时采用 `Asia/Shanghai`，不随服务器所在时区改变。

平台为每轮输入保存接收时间和该任务的 Agent 时区。Web 使用任务接收时间，渠道使用持久化入站记录的接收时间；排队、工具调用和后续模型请求沿用同一时间基准。Runtime 将接收时间、本地日期时间、星期和时区作为独立文本块放在本轮用户输入前，帮助理解“今天”“明天”等相对日期。界面中的用户原文保持不变；聊天记录显示的是浏览器本地日期和时间，悬停可查看时区。

动态时间不拼入角色指令，也不刷新历史消息中的时间。稳定指令及已有历史可继续复用模型的前缀缓存；实际命中仍取决于服务端缓存、工具配置和上下文裁剪。时间基准反映本轮消息接收时刻，不是持续刷新的实时时钟；长时间运行中暂不提供额外的当前时间工具。历史被裁剪或摘要后，对应时间也随所属轮次按同一策略处理。

## 会话限制

允许类型为“仅私聊”“仅群聊”或“两者都允许”。Web 对话属于私聊，选择仅群聊后，Web 保留历史查看和任务取消，不能创建或提交新的私聊。渠道受限消息记录为拒绝，不创建 Agent 任务。

群聊范围决定上下文如何查找，不改变回复的聊天位置：

| 范围 | 相同群的不同成员 | 同一成员在不同群 | 群聊与私聊 |
| --- | --- | --- | --- |
| 按群内成员隔离 | 独立上下文 | 独立上下文 | 独立上下文 |
| 全群共享 | 共同上下文、按队列顺序处理 | 不同群仍独立 | 独立上下文 |

两种范围都继续按渠道和 Agent 隔离。共享模式下，一个成员的问题、模型回答和工具结果可能用于其他成员的回答；适合协作场景，管理员应按实际资料访问需求选择。切换范围使用各自的会话映射，切回时可继续之前该范围的会话，超过空闲时限则创建新会话。

“空闲多久后开启新会话”仅作用于渠道，0 表示关闭，最多 10080 分钟（7 天）。平台依据该会话最后任务接收、回答/工具进度及结束事件的最新时间判断空闲；没有任务时使用会话创建时间。只要还有执行中或排队任务，就继续原会话。自动开启新会话保留旧历史，不迁移旧上下文。Web 中由管理员显式新建会话。

“允许用户通过 /new 开启新会话”只控制渠道中的精确 `/new` 命令。禁用后返回说明；不限制管理员的 Web 新建、查看和清理。共享群中任何成员重置都会影响全群后续会话，不取消旧任务。适配器必须提供可识别的命令文本；企微若在正文保留 @ 前缀，带前缀的文本不被当作精确命令。

## 上下文策略

模型窗口与最大输出在模型连接中设置。输入预算为窗口减去最大输出，Agent 策略决定其中携带哪些历史。一轮指用户提问及其后所有助手消息、工具调用和工具结果；最多轮数包含当前提问。所有策略保留角色、工具定义和当前输入。

| 策略 | 运行行为 | 建议用途 |
| --- | --- | --- |
| 最近若干轮 | 保留最近 1–200 轮；超预算时继续移除最早完整轮次 | 默认选项、日常问答 |
| 近期时间窗口 | 保留最近指定分钟内的历史，同时限制最多轮数；仍可按预算移除更早轮次 | 临时咨询、服务机器人 |
| 自动摘要压缩 | 接近输入预算的指定比例时，用当前模型压缩较早内容，保留摘要和近期原文 | 长期任务、连续协作 |
| 完整历史 | 携带当前有效历史，超过预算时停止并提示新建会话 | 较短且要求原文连续的任务 |

时间窗口为 1–43200 分钟（最多 30 天）；判断时点为任务开始执行时，当前提问始终保留。裁剪只影响本次模型请求，不删除 Runtime 原文或平台聊天记录。工具调用及结果随所属用户轮次整体保留，不会把工具结果单独发送给模型。

裁剪后的 Token 估算使用实际选中消息，忽略旧响应中对应旧历史的累计 usage。Token 估算仍与供应商精确分词有差异；当前单条输入、指令、工具定义或本轮工具往返本身过大时，仍会明确失败，不截断用户问题或悄悄移除正在处理的工具结果。内部另有独立的 8 MiB 请求保护；近期策略不因完整归档历史变长而禁止后续提交。

摘要阈值为输入预算的 50–90%，默认 70%；近期原文预算为 128–32768 Token，默认 4096，并根据实际可用窗口自动缩小。摘要由 Pi Durable 的原生 compaction 完成，不另建模型循环；关闭后台压缩和请求自动重试，压缩受本次任务时限控制。压缩过程产生诊断事件，摘要保存在 Runtime 会话中并可在重启后继续使用。摘要请求失败时停止本次任务，保留历史和工具记录，不自动重跑整个任务。

摘要会增加模型用量，也可能遗漏细节。自动摘要影响该会话的后续有效上下文；切换为完整历史不会撤销已有摘要。需要完全重新开始时，应新建会话。需要长期可靠保留的资料宜放入知识库，而不是只依赖会话摘要。

## 高级工具

“基本信息”中有一个总开关：允许此 Agent 使用本地工作区工具（`read`、`write`、`edit`、`bash`）。默认关闭，关闭时这些工具不会注册，也不会进入模型上下文。开启需要勾选风险确认，保存后写入审计记录；关闭同样记录。开启后 Runtime 必须把这四个工具同时加入本次运行的扩展与工具清单，否则模型只会看到知识库、附件和 Skill 读取能力；Runtime 测试会验证工具列表及 `bash` 的实际执行。

工作目录为 `<data>/workspaces/<agent_id>/`，不是操作系统沙箱。对外客服、纯知识库问答建议保持关闭。部署级 `SIAGENT_DISABLE_ADVANCED_TOOLS=true` 会覆盖所有 Agent：界面显示已被部署策略禁用，保存开启请求被拒绝，即使数据库里残留开启状态，派发时也会强制关闭。

## 回复输出

提供三个预设，也可逐项修改：

| 预设 | 思考摘要 | 工具过程 | 检索来源 | 渠道处理中提示 |
| --- | --- | --- | --- | --- |
| 简洁回复 | 隐藏 | 隐藏 | 展示 | 关闭 |
| 均衡展示 | 隐藏 | 简要状态 | 展示 | 开启 |
| 完整展示 | 展示 | 参数与结果 | 展示 | 开启 |

思考开关只展示模型接口实际返回的推理文本或摘要，不生成或推断模型未提供的过程，也不改变模型连接的推理强度。Web 中与最终回答分开展示，可展开查看；渠道最终回复按配置附加思考摘要。单次运行最多向平台保留 64000 字符的思考展示。关闭展示不改变模型或 Runtime 的私有持久化行为。

工具“隐藏”不在普通聊天中展示工具过程；“简要”显示名称和状态；“详细”在 Web 中按需鉴权获取参数和结果，在渠道最终回复中附带截取的详情。渠道每次调用最多展示参数 1000 字符、结果 2000 字符，最多 50 次调用，超出明确提示在后台查看。底层工具详情仍按原有规则保存、脱敏和截断。管理员的运行详情始终保留审计入口，展示开关不改变工具执行权限。

来源开关控制平台附加的本轮检索来源列表，不删除模型自行写入正文的引用。处理中提示只作用于渠道：消息排队超过 30 秒发送“正在排队”，模型已开始处理则仅在实际运行超过 90 秒时发送一次“仍在处理”；普通问答通常只收到最终回复。关闭后不再发送任何中间提示。错误、取消及结果不明仍保留状态说明。

输出配置控制平台展示，不能强制清除模型自行写入最终回答中的思考描述、工具叙述或其他内容。详细工具输出可能包含业务数据，管理员应结合接收者和群共享范围选择。

## API 与数据

`POST /api/agents`、`PUT /api/agents/{id}` 和兼容 `/api/agent` 接收 `policy`；读取 Agent 同时返回完整策略。旧客户端省略 `policy` 时保留原策略；传入部分字段时基于原值合并，非法枚举、范围和未知字段拒绝。

```json
{
  "name": "团队助手",
  "enabled": true,
  "model_id": 1,
  "instructions": "请清楚、准确地回答。",
  "policy": {
    "timezone": "Asia/Shanghai",
    "session": { "types": "all", "group_scope": "shared", "idle_minutes": 60, "allow_reset": false },
    "context": { "strategy": "recent", "max_turns": 20, "max_age_minutes": 1440, "summary_threshold": 70, "keep_recent_tokens": 4096 },
    "output": { "thinking": false, "tools": "summary", "sources": true, "progress": true }
  }
}
```

schema **10** 为 `agents` 增加 `policy`，为 `runs` 增加 `thinking`；当前 schema **23**，自动从版本 1–22 迁移，保留认证、凭据、会话、消息、工具和渠道数据。运行快照内保存完整策略，旧格式快照仍可读取。升级前停止服务并完整备份，旧程序不能直接读取 schema 21，回退须恢复旧备份。

渠道适配器通过 `chat_type`、`sender_id`、`group_id` 传入稳定身份，由平台决定上下文范围。兼容旧企微三元组 session；只提供不透明 session 的旧适配器按私聊处理，不能借此声明群共享，协议见 [channel-adapters.md](channel-adapters.md)。
