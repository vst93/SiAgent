# 工作区使用

顶部通过“Agent 对话”和“配置”切换两种使用场景。两者共用现有登录与数据；分区不会创建新的用户角色或改变权限体系。

## 日常对话

在“Agent 对话”选择助手、创建会话和发送消息。左侧只显示当前助手的会话历史；移动端通过“对话记录”展开。正文支持 Markdown 标题、列表、引用、表格、任务列表与代码块，包括历史和流式回复；代码与宽表格在各自区域横向滚动。原始 HTML 按文本展示，危险 URL 被过滤，图片作为显式链接打开，不自动请求远程图片。运行状态、取消、回答来源和本次运行详情随消息展示，通过标题栏的删除图标打开确认弹窗，核对后清理历史；取消或 Esc 关闭弹窗，不占据输入区空间。

切到配置时，当前会话继续接收流式事件，未提交的输入草稿保留。切回后继续原会话，不重新运行任务。刷新页面会读取持久化历史；输入草稿只保留在当前页面内存中。

## 服务端配置

配置区使用固定功能栏目，桌面为侧栏、移动端为横向导航：

| 栏目 | 职责 |
| --- | --- |
| 模型连接 | 连接名称、协议和凭据、上下文/输出长度、推理/采样、兼容字段、连接测试及归档 |
| Agent | 基本信息与模型选择；会话限制、上下文和回复输出；知识库关联；Skills/MCP 工具授权 |
| 知识库 | 创建资料范围、上传和更新文档、处理状态、测试检索、来源 |
| 插件接入 | Skills/MCP 独立页签；上传和浏览技能文件、维护 MCP 服务及测试连接 |
| 渠道接入 | 选择已安装适配器、绑定 Agent、连接状态、入站和投递诊断 |
| 运行与维护 | 执行限制、服务状态、队列数量、磁盘统计与低空间提示 |

模型页默认仅展开连接与上下文配置，推理、采样和兼容设置按需展开。模型名称支持按当前未保存配置获取模型列表、下拉选择和手动填写，获取结果不持久化。知识库使用顶部选择器及文档管理/检索测试页签，管理和新建按钮组成同高相邻操作组；创建、上传、替换和删除通过弹窗完成，文档行提供筛选和更多操作。

插件页支持 ZIP、SKILL.md 或本机文件夹上传，由系统创建并管理技能目录，使用文件树查看资源；不再填写服务器目录。Skills/MCP 页签切换保留编辑与浏览状态。

Agent 的会话限制、上下文及回复输出与基本信息一起保存；知识库和工具授权分别保存。策略选择与实际行为见 [Agent 策略说明](agent-policy.md)。

资源只在对应栏目维护。Agent 页面选择已保存的模型与资源，独立保存授权；导入 Skill、连接 MCP 或创建知识库不会自动赋予任何 Agent 使用权限。首次登录且没有模型时会引导进入模型连接，首次保存后自动创建默认 Agent 并进入对话。

渠道配置根据适配器字段声明生成，默认企微智能机器人长连接（BotID/Secret），自建应用作为兼容选项保留；新增可信进程适配器见 [channel-adapters.md](channel-adapters.md)。该重构不新增 OpenAI 兼容服务端或知识库 MCP 双向适配。

## 布局与图标

顶部采用紧凑导航，移动端在同一行保留品牌标记、模块切换、默认页星标与退出入口。配置页面合并重复标题提示，收紧侧栏、表单与资源列表的纵向间距；对话输入框默认两行，随内容自动增高。

系统图标统一使用 Phosphor Icons，经 `web/src/icons.tsx` 的公共组件引用。默认页仍通过星形图标固定，实心状态表示已选中；纯图标按钮保留明确的辅助名称和键盘操作。新增图标、尺寸、颜色和间距约定见 [界面与图标规范](ui-guidelines.md)。

## 默认打开的页面

- 对话模块旁的 ☆：默认打开 Agent 对话。
- 配置模块旁的 ☆：默认打开当前配置栏目，例如“配置 · 知识库”。从对话区操作时使用上次访问的配置栏目。
- ★ 表示当前目标已经固定。固定后浏览其他栏目不会改变默认页；再次固定其他页面即可替换。

偏好保存在当前浏览器的本地存储中，不包含模型密钥，不写入服务器配置。清除浏览器存储或更换浏览器后恢复为默认打开对话。浏览器拒绝存储时页面显示提示，切换仍可使用；已有页面在其他标签更改默认页时同步其固定状态。

具体链接优先于默认页，例如 `/#/chat`、`/#/settings/agents`、`/#/settings/knowledge`。不带页面片段的工作台地址按浏览器保存的默认页打开。前进/后退保留导航语义；未知片段或无效偏好回退到有效默认页。回答来源继续通过独立的 `/?source=…` 页面打开，优先展示来源，不受默认模块影响。

## 验证

`web/test/browser.mjs` 使用实际 Go/Node 进程和本地协议测试服务，覆盖首次配置、模块与默认栏目切换、草稿保留、深链接和前进后退，以及模型、Agent、知识库、插件、企微、维护原有操作；包含桌面与 320px／390px 移动布局、模型参数实际请求、删除弹窗取消/Esc/确认与标签图标。外部模型、第三方 MCP 和真实企业微信的生产验收仍单列在发布检查中。
