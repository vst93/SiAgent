# 工作区使用

左侧导航通过“Agent 对话”和配置分组切换两种使用场景。两者共用现有登录与数据；分区不会创建新的用户角色或改变权限体系。

## 日常对话

在“Agent 对话”选择助手、创建会话和发送消息。左侧只显示当前助手的会话历史；移动端通过“对话记录”展开。正文支持 Markdown 标题、列表、引用、表格、任务列表与代码块，包括历史和流式回复；代码与宽表格在各自区域横向滚动。原始 HTML 按文本展示，危险 URL 被过滤，图片作为显式链接打开，不自动请求远程图片。运行状态、取消、回答来源和本次运行详情随消息展示，通过标题栏的删除图标打开确认弹窗，核对后清理历史；取消或 Esc 关闭弹窗，不占据输入区空间。

消息时间显示日期及浏览器本地时间，悬停可查看完整时间与时区。渠道会话在标题栏标明“私聊 · 用户 ID”或“群聊 · 群 ID”并附“只读”，用户消息显示真实发送者（群聊按每条消息区分成员），隐藏输入框和发送按钮，保留运行详情与任务取消；新消息须从原聊天平台发送。旧数据缺少渠道身份时回退为“渠道对话”和“渠道用户”。切换会话时先展示读取状态，避免短暂显示上一会话内容。

切到配置时，当前会话继续接收流式事件，未提交的输入草稿保留。切回后继续原会话，不重新运行任务。刷新页面会读取持久化历史；输入草稿只保留在当前页面内存中。

## 服务端配置

配置区使用固定功能栏目，桌面为常驻侧栏、移动端为抽屉导航。导航按“助手配置 / 模型与渠道 / 扩展与集成 / 系统”分组：Agent、知识库、技能与工具放在同一组，模型连接、用量统计与渠道接入放在同一组，扩展插件、集成接口和接口文档归入扩展与集成，减少在配置之间来回跳转：

| 分组 | 栏目 | 职责 |
| --- | --- | --- |
| 助手配置 | Agent | 基本信息与模型选择；会话限制、上下文和回复输出；知识库关联；Skills/MCP 工具授权；复制助手 |
| 助手配置 | 知识库 | 创建资料范围、上传和更新文档、处理状态、测试检索、来源 |
| 助手配置 | 技能与工具 | Skills/MCP 独立页签；上传和浏览技能文件、维护 MCP 服务及测试连接 |
| 模型与渠道 | 模型连接 | 连接名称、协议和凭据、上下文/输出长度、推理/采样、兼容字段、连接测试及归档 |
| 模型与渠道 | 用量统计 | 按时间范围查看 tokens 趋势、模型拆分与会话消耗；未返回用量的调用按 0 记录 |
| 模型与渠道 | 渠道接入 | 选择已安装适配器、绑定 Agent、连接状态、入站和投递诊断 |
| 扩展与集成 | 扩展插件 | 安装、启停、回滚扩展包，查看健康状态与事件 |
| 扩展与集成 | 集成接口 | API 密钥、Webhook 与业务系统调用 |
| 扩展与集成 | 接口文档 | 认证、任务、知识库、Webhook 与 MCP 对接说明 |
| 系统 | 运行与维护 | 执行限制、服务状态、队列数量、磁盘统计与低空间提示 |

模型页默认仅展开连接与上下文配置，推理、采样和兼容设置按需展开。模型名称支持按当前未保存配置获取模型列表、下拉选择和手动填写，获取结果不持久化。知识库使用顶部选择器及文档管理/检索测试页签，管理和新建按钮组成同高相邻操作组；创建、上传、替换和删除通过弹窗完成，文档行提供筛选和更多操作。

插件页支持 ZIP、SKILL.md 或本机文件夹上传，由系统创建并管理技能目录，使用文件树查看资源；不再填写服务器目录。技能详情采用固定高度的工作区：左侧文件树独立滚动，右侧文件栏显示完整路径、大小和“预览 / 编辑”切换，正文在栏内滚动，编辑时字符数与保存按钮固定在底部，不再随长内容滚出视野。Skills/MCP 页签切换保留编辑与浏览状态。

Agent 的会话限制、上下文及回复输出与基本信息一起保存；知识库和工具授权分别保存。策略选择与实际行为见 [Agent 策略说明](agent-policy.md)。

资源只在对应栏目维护。Agent 页面选择已保存的模型与资源，独立保存授权；导入 Skill、连接 MCP 或创建知识库不会自动赋予任何 Agent 使用权限。首次登录且没有模型时会引导进入模型连接，首次保存后自动创建默认 Agent 并进入对话。

渠道配置根据适配器字段声明生成，默认企微智能机器人长连接（BotID/Secret），自建应用作为兼容选项保留；新增可信进程适配器见 [channel-adapters.md](channel-adapters.md)。该重构不新增 OpenAI 兼容服务端或知识库 MCP 双向适配。

## 配置页结构

配置页共享一个内容宽度和一套面板几何：所有栏目使用同一条 1120px 居中内容列，左侧目录与右侧详情都是同款面板；`运行与维护` 按“运行状态、存储、应用更新、运行限制、知识库上传限制”五个面板分组，状态数字用等宽字体，限制表单各自保存并就近显示结果。Agent、插件、知识库的页签统一为下划线选中态；API 密钥和扩展按面板分区，扩展列表内不再嵌套卡片。页面身份在窗口栏面包屑出现一次，内容区不再重复标题和说明；具体操作位于对应面板的标题行或底部操作行。

`用量统计` 使用同一内容列，顶部提供近 7/30/90 天、全部和自定义日期筛选；汇总总 tokens、输入、输出、缓存与调用次数，趋势按小时/天/周/月分桶，并给出按模型和按会话的拆分。会话头部同时显示本会话累计 tokens；模型服务未返回 usage 时写入 0，并在看板中标注有多少调用按 0 记录。

## 桌面式列表与操作

列表行操作使用统一的浮层菜单：菜单挂载在页面顶层，不会被卡片或滚动区域的 `overflow` 裁剪，接近视口底部时自动向上展开，跟随滚动重新定位，支持方向键、Home/End 与 Escape。知识库文档列表使用吸顶表头、独立滚动区域和固定操作列；支持多选、全选当前筛选结果与批量删除。桌面宽度下，Agent、技能库和渠道的左侧目录保持可见并在自身区域内滚动，右侧详情独立滚动。按钮、输入框与列表行统一高度和焦点样式，减少页面级滚动与跳动。

## 布局与图标

桌面端采用常驻侧栏 + 工作区内容；对话为侧栏 + 对话记录 + 主区三栏，窄窗口可收起对话记录。按 `⌘K` / `Ctrl K` 或点击侧栏“搜索或跳转”可打开命令面板，快速跳转页面、新建对话或切换主题。配置页不重复页面标题，页面身份由窗口栏承担。移动端在同一行保留菜单、页面标题与主题切换，导航和账户操作收进抽屉；对话输入框默认两行，随内容自动增高。主题可在浅色和深色之间切换，偏好保存在当前浏览器。

系统图标统一使用 Phosphor Icons，经 `web/src/icons.tsx` 的公共组件引用。默认页仍通过星形图标固定，实心状态表示已选中；纯图标按钮保留明确的辅助名称和键盘操作。新增图标、尺寸、颜色和间距约定见 [界面与图标规范](ui-guidelines.md)。

## 默认打开的页面

- 对话模块旁的 ☆：默认打开 Agent 对话。
- 配置模块旁的 ☆：默认打开当前配置栏目，例如“配置 · 知识库”。从对话区操作时使用上次访问的配置栏目。
- ★ 表示当前目标已经固定。固定后浏览其他栏目不会改变默认页；再次固定其他页面即可替换。

偏好保存在当前浏览器的本地存储中，不包含模型密钥，不写入服务器配置。清除浏览器存储或更换浏览器后恢复为默认打开对话。浏览器拒绝存储时页面显示提示，切换仍可使用；已有页面在其他标签更改默认页时同步其固定状态。

具体链接优先于默认页，例如 `/#/chat`、`/#/settings/agents`、`/#/settings/knowledge`。不带页面片段的工作台地址按浏览器保存的默认页打开。前进/后退保留导航语义；未知片段或无效偏好回退到有效默认页。回答来源继续通过独立的 `/?source=…` 页面打开，优先展示来源，不受默认模块影响。

## 验证

`web/test/browser.mjs` 使用实际 Go/Node 进程和本地协议测试服务，覆盖首次配置、模块与默认栏目切换、草稿保留、深链接和前进后退，以及模型、Agent、知识库、插件、企微、维护原有操作；包含桌面与 320px／390px 移动布局、模型参数实际请求、删除弹窗取消/Esc/确认与标签图标。外部模型、第三方 MCP 和真实企业微信的生产验收仍单列在发布检查中。

## 外观与对话操作

右上角/侧栏的主题按钮循环切换三种状态并即时生效，保存在当前浏览器：

| 状态 | 行为 |
| --- | --- |
| 浅色 | 固定浅色 |
| 深色 | 固定深色 |
| 自动 | 按本机时间切换：07:00–18:59 浅色，19:00–06:59 深色；页面每分钟检查一次，跨过时间边界无需刷新 |

自动模式只依据浏览器本地时间，不使用地理位置或日出日落计算——自托管实例没有位置数据，固定时间窗可预测。命令面板中的“外观”项同样在三态间循环。

对话工作区提供以下阅读辅助：

- 消息头部显示提问轮数与消息总数；每条消息在悬停或用键盘聚焦时出现复制按钮，复制该条正文并就地反馈“已复制”。
- 工具栏“复制对话”把整段对话导出为 Markdown（标题为会话标题，逐条以“## 用户/助手”分段），便于粘贴到工单或文档。
- 思考摘要展开后可单独复制；剪贴板不可用时（例如纯 HTTP 部署）自动退回隐藏文本框方案，仍失败则在页面顶部提示手动选择。

左侧栏收起后，底部四个操作按钮改为单列垂直排列，导航区域不再出现横向滚动条。技能列表与“关联 Agent”面板使用与其它目录一致的行卡片与胶囊标签样式。

手机（≤980px）下的布局约定：

- 对话页的操作区（选择助手、新对话、对话记录、删除会话）放在标题栏内**单行**排列：助手选择器占据剩余宽度，其余为 32px 图标按钮，标题栏高度从 139px 降到 93px。此前它在输入框上方另有一条工具栏，实际被挤到屏幕外，导致手机上找不到切换对话的入口。“复制对话”在手机上移入对话记录面板，桌面仍留在标题栏。对话记录面板最多占 `46dvh`（上限 420px）且自身滚动，选择后自动收起。
- 渠道只读会话的说明只保留“请在原聊天平台发送新消息。”，不再重复说明可查看记录和取消任务（这些由按钮本身表达）。
- 技能列表在窄屏只隐藏描述，标题与文件数始终显示——早期规则隐藏了行内所有 `span`，导致列表看起来是空白的。
- 知识库的卡片在手机上不再裁剪内容，文档较多时由页面整体滚动，最后一行可以到达。此前的 `max-height: calc(100dvh - 320px)` 只在桌面生效，因为它在手机上把列表裁剪成一屏高、卡片背景只铺一屏；现在这条规则收进 `min-width: 901px` 媒体查询。
- 技能详情中的文件树强制左对齐并保留层级缩进；“关联 Agent”是一条带分隔线的内嵌行，左右内边距与标题、描述一致（18px），不再单独套卡片外壳。
- 技能列表在手机上不再限制为 190px 高的小窗口，随页面正常滚动；列表顶部新增排序下拉，支持“名称 A→Z”“最近上传”“文件数最多”“体积最大”，选择保存在当前浏览器。排序只改变显示顺序，当前选中的技能保持不变。
- 知识库工具栏的“管理知识库”和“新建知识库”统一为同一高度与内边距；评测页拆成“新增评测问题”和“运行评测”两个区块，导入/导出作为运行区块内的次级操作。
