# 界面语言（i18n）

首版支持 **简体中文** 和 **英文**，默认中文。语言只影响当前浏览器，不改变服务端数据、Agent 指令、知识库内容或已有对话。

## 使用

- 桌面顶栏右侧、移动端导航抽屉、登录/首次设置页均有语言切换按钮。
- 选择结果保存在浏览器 `localStorage["siagent.language"]`，值为 `zh` 或 `en`；刷新、重启浏览器后继续生效。
- 切换后 `document.documentElement.lang` 同步为 `zh-CN` 或 `en`。
- 未设置或值无效时回退中文，因此现有中文用户和浏览器测试不受影响。

## 覆盖范围

- 导航、顶栏、移动端抽屉、登录/首次设置、Agent 对话、运行详情、配置页、表单、按钮、空状态、提示、知识库、模型、插件、渠道、扩展、集成接口、运行与维护。
- “接口文档”页提供独立的中英文 Markdown，不依赖逐句翻译。
- 服务端返回的动态文本、用户输入的 Agent/知识库/文档名称、对话内容不做强制翻译；无法匹配的句子会按术语表做保守替换。

## 实现

- `web/src/i18n.ts`：语言持久化、文本/属性翻译、DOM 观察器与切换恢复。
- `web/src/i18n-dict.ts`：中文源字符串到英文的精确映射，以及长句/动态文本的术语表。
- `web/src/main.tsx`：语言状态、切换按钮和 `applyLanguage()` 生命周期。
- `web/src/configuration.tsx` / `web/src/api-docs.tsx`：接口文档的中英文内容。

新增界面文案时：

1. 先在中文界面完成文案；
2. 在 `i18n-dict.ts` 的 `exact` 中添加完整中文句子与英文；
3. 如果句子包含变量或多个按钮拼接，优先补完整短句，避免只依赖单字术语；
4. 运行 `npm --prefix web run build`，再执行浏览器测试。

翻译层不会改写 `input`/`textarea` 的值，也不会翻译聊天正文、Markdown 用户内容或带 `data-i18n-skip` 的区域。

## 验证

- 默认中文：现有浏览器测试全部使用中文断言。
- 英文切换：移动端导航中切换到英文，检查导航、配置页和 `document.documentElement.lang`；刷新后确认持久化；切回中文确认恢复。
- 子路径部署：`/siagent/` 下语言切换与刷新同样工作。
